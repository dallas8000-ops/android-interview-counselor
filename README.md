# android-interview-counselor
Real-time interview assistance app for full-stack developer interviews.

## Features
- Speech recognition for detecting interview questions
- AI-powered answers for full-stack topics (React, Node.js, Databases, System Design)
- Text-to-speech for hands-free reading
- Dark theme optimized for tablet use during Zoom calls

## Setup
1. Open in Android Studio
2. Sync Gradle
3. Run on Android tablet (API 24+)
4. Place near PC speakers during interview

## Usage
- Tap microphone button to start listening
- App automatically detects technical questions
- Read answers on screen or listen via TTS
